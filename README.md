# Balcão de Serviços

Projeto de estudo de um sistema de assistência técnica em C# e Windows Forms, com .NET Framework 4.8 e SQL Server.

A primeira entrega terá cadastro de clientes, ordens de serviço e histórico de atendimento. A solução usa projetos tradicionais do Visual Studio, restaurados pelo NuGet e compilados pelo MSBuild.

O desenvolvimento e a validação desta primeira versão serão registrados em uma pull request.
