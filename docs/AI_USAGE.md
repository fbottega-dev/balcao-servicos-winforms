# Apoio de IA

Ferramentas de IA ajudaram a estruturar e implementar este projeto, escrever os testes, revisar o código e preparar a documentação. O escopo foi mantido pequeno para permitir acompanhar uma operação da tela até o banco.

O histórico do Git e as execuções do CI registram as alterações e verificações realizadas. A existência de testes não dispensa executar o aplicativo e conferir o fluxo de atendimento.

O roteiro [COMO-EXPLICAR.md](COMO-EXPLICAR.md) ajuda a percorrer as regras e o caminho de uma operação. Fazer uma pequena mudança e escrever seu teste é uma forma de conferir o próprio entendimento antes de apresentar o projeto.
